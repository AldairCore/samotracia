# apps/web

App Vue 3 + TypeScript + Vite.

- `src/App.vue`: página con la colección, selector de colores, foco por grupo y ficha al pasar el cursor.
- `src/components/MandalaCanvas.vue`: envoltorio Vue de `MandalaFigure`.
- `src/data/core-lore.json`: datos de Core.Lore en forma de `FigureData` (mientras no haya importación desde Spotify).

```bash
npm run dev -w apps/web
```
